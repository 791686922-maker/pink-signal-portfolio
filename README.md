# 粉色信号农场

一个为科技内容创作者设计的原创像素风个人网站。页面把文章、项目、个人介绍、读者互动与联系方式组织成一座从白天走向夜晚的粉色农场。

## 本地运行

Windows 用户可以直接双击 `打开粉色信号农场.cmd`。脚本会安装缺失依赖、启动本地服务并打开浏览器。

也可以在终端运行：

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

不要直接双击项目根目录的 `index.html`。这是 Vue + Vite 源码入口，必须先编译；浏览器用 `file://` 打开时无法加载源码模块，因此会看到空白页。

## 内容替换

- 姓名、首屏文案与导航：`src/App.vue`
- 文章、项目、个人介绍与社交链接：`src/data/content.ts`
- 联系区演示表单：`src/components/NightSignal.vue`

当前文章、项目、履历、社交链接和表单都明确标记为示例，发布前请替换为真实资料。

## 主要互动

- 10 节点弹性像素尾线，支持磁吸、拉拽、投放和回弹
- 可拉动的樱花树、Canvas 像素花瓣雨与尾线捕捉
- 可按住连续照料、可拖入工具的 4 × 4 持久化花圃
- 文章调频、溪流长短拍、猫亲密度、阁楼工具序列与星座连线
- 三条跨章节彩蛋链、口袋电台和约 8.6 秒的零点广播终局
- 横向移动生长灯与可被旧电池复活的失败项目
- 两组不影响输入框操作的键盘彩蛋
- 桌面、触屏与减少动态效果模式的独立降级策略

浏览器验收：

```bash
npm run test:e2e
```

全部场景与像素图形由 HTML、CSS、Canvas 和少量内联 SVG 原创绘制，没有复制游戏素材。
